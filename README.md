# Lucas Wesson

AI and security, Bremerton, WA. I train AI systems, break them, and build the tooling that keeps them honest.

Model evaluation at xAI and OpenAI, independent vulnerability research on HackerOne and Bugcrowd, and the open source tools that come out of both. The throughline is honest evaluation: decide what good looks like, write it down, then test whether it held.

## Projects

| Project | What it is |
|---|---|
| [RedBreach](https://github.com/Lwesson/RedBreach) | Security testing platform for authorized engagements, recon to report. Findings are deduplicated, CVSS scored, mapped to CWE and ATT&CK, and held behind a human review gate. Optional AI layer runs on Claude, OpenAI, or a local model. Python, 510 tests, MIT. |
| [Cold Open](https://github.com/Lwesson/cold-open) | A daily security puzzle: cipher breaking, log forensics, and network traffic analysis, generated from the date with no backend. Every puzzle has exactly one defensible answer, and the tests enforce it. [Play it](https://lwesson.github.io/cold-open/). |
| [TTB Label Verifier](https://github.com/Lwesson/ttb-label-verifier) | Vision model compliance checker for alcohol labels against 27 CFR, built as a federal take-home. Uncertain reads go to a person instead of a guess. Python and React, 115 tests. |
